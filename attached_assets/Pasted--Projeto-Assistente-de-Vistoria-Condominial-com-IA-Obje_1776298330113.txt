# 🚀 Projeto: Assistente de Vistoria Condominial com IA

## 🎯 Objetivo

Construir uma aplicação web onde um síndico possa:

1. Enviar:

   * Áudio (vistoria)
   * Imagens
   * Informações adicionais (opcional)

2. O sistema deve:

   * Transcrever o áudio
   * Analisar imagens
   * Gerar automaticamente um comunicado profissional

3. Permitir:

   * Visualizar o comunicado
   * Editar manualmente (opcional)
   * Enviar via WhatsApp (integração futura via API)

---

# 🏗️ Arquitetura

## Backend

* Python + FastAPI

## Frontend

* React (simples, pode usar Vite)
* UI limpa e funcional (não precisa design complexo)

## Integrações

* OpenAI API (transcrição + análise imagem)
* Claude API (geração do comunicado)

---

# ⚙️ Funcionalidades obrigatórias

## 1. Tela principal

Criar uma página com:

* Upload de áudio
* Upload de múltiplas imagens
* Campo de texto opcional:

  * "Observações adicionais"
* Botão:

  * "Gerar comunicado"

---

## 2. Backend endpoint

Criar endpoint:

POST /generate-report

Recebe:

* audio file
* images[]
* notes (string)

---

## 3. Processamento IA (pipeline)

### Etapa 1 — OpenAI

* Transcrever áudio (Whisper)
* Analisar imagens (Vision)

Retornar:

{
"transcription": "...",
"image_analysis": "...",
"structured_data": {
"possible_issue": "...",
"location": "...",
"details": "..."
}
}

---

### Etapa 2 — Claude

Enviar para Claude:

INPUT:

* transcription
* image_analysis
* notes

INSTRUCTION:

"Você é um síndico profissional.

Analise as informações e gere:

1. Tipo do problema
2. Nível de urgência (baixa, média, alta)
3. Ação recomendada
4. Um resumo curto (até 2 linhas)
5. Um comunicado formal para moradores

Use linguagem clara, profissional e sem termos técnicos desnecessários."

---

Retornar JSON:

{
"tipo": "...",
"urgencia": "...",
"acao": "...",
"resumo": "...",
"comunicado": "..."
}

---

## 4. Frontend resultado

Após gerar:

Exibir:

* Tipo
* Urgência
* Ação
* Resumo
* Comunicado (editável)

---

## 5. Botão adicional

Botão:

"Enviar via WhatsApp"

(Apenas mockar por enquanto com console.log ou placeholder)
